Digital Clock Portable — Apps & Games
=====================================

Official website:
https://appsandgames.org/digital-clock

Portable edition
----------------
Digital Clock Portable contains the same clock interface and main functions as the regular Windows edition, but it does not install Digital Clock or the Windows Screen Saver.

ENGLISH
-------
1. Download DigitalClock-Portable-x64.zip only from the official Apps & Games download link.
2. Right-click the ZIP file and choose Extract All.
3. Move the extracted DigitalClock-Portable-x64 folder anywhere you want, for example to Documents, another drive or a USB drive.
4. Open the folder and run DigitalClock.Windows.exe.
5. If Microsoft Defender SmartScreen shows "Windows protected your PC" because the app is not yet digitally signed and the publisher is shown as "Unknown publisher", click More info if necessary and then Run anyway. Continue only when the ZIP came from the official Apps & Games download domain and its SHA-256 matches the value published on the Digital Clock download page.
6. Keep the complete folder together. Do not run the EXE directly from inside the ZIP archive.
7. Your portable settings and local data are stored inside the Data folder next to the application.
8. The Windows Screen Saver is not included in the portable edition. Use the regular Windows installer if you want the optional Screen Saver.
9. Microsoft Edge WebView2 Runtime is required. It is already present on most Windows 10/11 systems. If Windows reports that WebView2 is missing, install the official Microsoft WebView2 Runtime and start Digital Clock again.
10. To update the portable edition, download the newest ZIP, close Digital Clock, extract the new version and replace the application files. Keep your existing Data folder if you want to preserve your portable settings.
11. The app's standard Info section is available inside Digital Clock and includes version, privacy, Apps & Games and donation information.

Note: Digital Clock Portable itself requires no installation. If you manually enable "Start with Windows" inside the app, Windows creates a startup entry for the current user. Disable that option before moving or deleting the portable folder.

HRVATSKI
--------
1. Preuzmi DigitalClock-Portable-x64.zip samo preko službene Apps & Games poveznice.
2. Desni klik na ZIP i odaberi Izdvoji sve / Extract All.
3. Raspakiranu mapu DigitalClock-Portable-x64 možeš premjestiti u Dokumente, na drugi disk ili USB memoriju.
4. Otvori mapu i pokreni DigitalClock.Windows.exe.
5. Ako Microsoft Defender SmartScreen prikaže "Windows protected your PC" zato što aplikacija još nije digitalno potpisana i kao izdavača prikazuje "Unknown publisher", klikni More info / Više informacija ako je potrebno, a zatim Run anyway / Svejedno pokreni. Nastavi samo ako je ZIP preuzet sa službene Apps & Games download domene i njegov SHA-256 odgovara vrijednosti objavljenoj na stranici Digital Clocka.
6. Drži cijelu mapu zajedno. Nemoj pokretati EXE izravno iz ZIP arhive.
7. Portable postavke i lokalni podaci spremaju se u mapu Data pokraj aplikacije.
8. Windows Screen Saver nije uključen u portable izdanje. Ako želiš opcionalni Screen Saver, koristi standardni Windows installer.
9. Potreban je Microsoft Edge WebView2 Runtime. Na većini Windows 10/11 računala već je instaliran. Ako Windows javi da nedostaje, instaliraj službeni Microsoft WebView2 Runtime i ponovno pokreni Digital Clock.
10. Za nadogradnju portable verzije preuzmi novi ZIP, zatvori Digital Clock, raspakiraj novu verziju i zamijeni aplikacijske datoteke. Zadrži postojeću mapu Data ako želiš sačuvati portable postavke.
11. Standardni Info nalazi se unutar aplikacije i sadrži verziju, privatnost, Apps & Games i informacije o donacijama.

Napomena: Digital Clock Portable ne zahtijeva instalaciju. Ako ručno uključiš "Pokreni sa sustavom Windows", Windows će napraviti startup zapis za trenutnog korisnika. Isključi tu opciju prije premještanja ili brisanja portable mape.

DEUTSCH
-------
ZIP herunterladen, vollständig entpacken und DigitalClock.Windows.exe aus dem entpackten Ordner starten. Wenn Microsoft Defender SmartScreen "Der PC wurde durch Windows geschützt" bzw. "Windows protected your PC" anzeigt, weil die App noch nicht digital signiert ist und "Unknown publisher" erscheint, bei Bedarf Weitere Informationen und danach Trotzdem ausführen wählen. Nur fortfahren, wenn die ZIP-Datei von der offiziellen Apps-&-Games-Download-Domain stammt und der veröffentlichte SHA-256-Wert übereinstimmt. Einstellungen werden im Unterordner Data gespeichert. Der Windows-Bildschirmschoner ist in der Portable-Version nicht enthalten. Für Updates die neue ZIP-Version entpacken und den vorhandenen Data-Ordner behalten.

ITALIANO
--------
Scarica il file ZIP, estrailo completamente e avvia DigitalClock.Windows.exe dalla cartella estratta. Se Microsoft Defender SmartScreen mostra "Windows protected your PC" perché l'app non è ancora firmata digitalmente e indica "Unknown publisher", fai clic su More info se necessario e poi su Run anyway. Continua solo se lo ZIP proviene dal dominio ufficiale di download di Apps & Games e il valore SHA-256 pubblicato corrisponde. Le impostazioni vengono salvate nella sottocartella Data. Lo screensaver di Windows non è incluso nella versione Portable. Per aggiornare, estrai il nuovo ZIP e conserva la cartella Data esistente.

ESPAÑOL
-------
Descarga el ZIP, extráelo completamente y ejecuta DigitalClock.Windows.exe desde la carpeta extraída. Si Microsoft Defender SmartScreen muestra "Windows protected your PC" porque la aplicación todavía no está firmada digitalmente y aparece "Unknown publisher", pulsa More info si es necesario y después Run anyway. Continúa solo si el ZIP procede del dominio oficial de descargas de Apps & Games y coincide el SHA-256 publicado. La configuración se guarda en la subcarpeta Data. El protector de pantalla de Windows no está incluido en la versión Portable. Para actualizar, extrae el nuevo ZIP y conserva la carpeta Data existente.
