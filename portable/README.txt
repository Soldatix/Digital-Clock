Digital Clock Portable — Apps & Games
=====================================

Official website:
https://appsandgames.org/digital-clock

Portable edition
----------------
Digital Clock Portable contains the same clock interface and main functions as the regular Windows edition, but it does not install Digital Clock or the Windows Screen Saver.

ENGLISH
-------
1. Download DigitalClock-Portable-x64.zip only from the official Apps & Games download link.
2. Right-click the ZIP file and choose Extract All.
3. Move the extracted DigitalClock-Portable-x64 folder anywhere you want, for example to Documents, another drive or a USB drive.
4. Open the folder and run DigitalClock.Windows.exe.
5. Keep the complete folder together. Do not run the EXE directly from inside the ZIP archive.
6. Your portable settings and local data are stored inside the Data folder next to the application.
7. The Windows Screen Saver is not included in the portable edition. Use the regular Windows installer if you want the optional Screen Saver.
8. Microsoft Edge WebView2 Runtime is required. It is already present on most Windows 10/11 systems. If Windows reports that WebView2 is missing, install the official Microsoft WebView2 Runtime and start Digital Clock again.
9. To update the portable edition, download the newest ZIP, close Digital Clock, extract the new version and replace the application files. Keep your existing Data folder if you want to preserve your portable settings.
10. The app's standard Info section is available inside Digital Clock and includes version, privacy, Apps & Games and donation information.

Note: Digital Clock Portable itself requires no installation. If you manually enable "Start with Windows" inside the app, Windows creates a startup entry for the current user. Disable that option before moving or deleting the portable folder.

HRVATSKI
--------
1. Preuzmi DigitalClock-Portable-x64.zip samo preko službene Apps & Games poveznice.
2. Desni klik na ZIP i odaberi Izdvoji sve / Extract All.
3. Raspakiranu mapu DigitalClock-Portable-x64 možeš premjestiti u Dokumente, na drugi disk ili USB memoriju.
4. Otvori mapu i pokreni DigitalClock.Windows.exe.
5. Drži cijelu mapu zajedno. Nemoj pokretati EXE izravno iz ZIP arhive.
6. Portable postavke i lokalni podaci spremaju se u mapu Data pokraj aplikacije.
7. Windows Screen Saver nije uključen u portable izdanje. Ako želiš opcionalni Screen Saver, koristi standardni Windows installer.
8. Potreban je Microsoft Edge WebView2 Runtime. Na većini Windows 10/11 računala već je instaliran. Ako Windows javi da nedostaje, instaliraj službeni Microsoft WebView2 Runtime i ponovno pokreni Digital Clock.
9. Za nadogradnju portable verzije preuzmi novi ZIP, zatvori Digital Clock, raspakiraj novu verziju i zamijeni aplikacijske datoteke. Zadrži postojeću mapu Data ako želiš sačuvati portable postavke.
10. Standardni Info nalazi se unutar aplikacije i sadrži verziju, privatnost, Apps & Games i informacije o donacijama.

Napomena: Digital Clock Portable ne zahtijeva instalaciju. Ako ručno uključiš "Pokreni sa sustavom Windows", Windows će napraviti startup zapis za trenutnog korisnika. Isključi tu opciju prije premještanja ili brisanja portable mape.

DEUTSCH
-------
ZIP herunterladen, vollständig entpacken und DigitalClock.Windows.exe aus dem entpackten Ordner starten. Einstellungen werden im Unterordner Data gespeichert. Der Windows-Bildschirmschoner ist in der Portable-Version nicht enthalten. Für Updates die neue ZIP-Version entpacken und den vorhandenen Data-Ordner behalten.

ITALIANO
--------
Scarica il file ZIP, estrailo completamente e avvia DigitalClock.Windows.exe dalla cartella estratta. Le impostazioni vengono salvate nella sottocartella Data. Lo screensaver di Windows non è incluso nella versione Portable. Per aggiornare, estrai il nuovo ZIP e conserva la cartella Data esistente.

ESPAÑOL
-------
Descarga el ZIP, extráelo completamente y ejecuta DigitalClock.Windows.exe desde la carpeta extraída. La configuración se guarda en la subcarpeta Data. El protector de pantalla de Windows no está incluido en la versión Portable. Para actualizar, extrae el nuevo ZIP y conserva la carpeta Data existente.
